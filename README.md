# 호치민 여행 가이드

2026년 12월 13일부터 16일까지의 호치민 3박 4일 여행 안내입니다. 날짜별 일정과 항공편을 확인할 수 있습니다. 숙소 5곳의 예약 정보와 사진 및 주요 명소를 소개합니다.

[공유 사이트 열기](https://mannomi.github.io/trip/)

GitHub Pages는 main 브랜치의 docs 폴더를 배포합니다. 별도 빌드 없이 docs/index.html에서 시작할 수 있습니다. 기존 안내와 섹션 링크는 새 페이지로 연결됩니다. 저장한 숙소와 출발 전 체크리스트는 해당 브라우저에 저장됩니다. 숙소 공유 링크를 열면 해당 숙소가 선택됩니다.
