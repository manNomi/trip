# 우리의 호치민

2026년 12월 13일부터 16일까지의 호치민 여행 안내입니다. 왕복 항공편과 숙소 예약 비교 및 일정과 맛집, 준비물을 한 페이지에 모았습니다.

[공유 페이지 열기](https://mannomi.github.io/trip/)

사이트는 GitHub Pages에서 `main` 브랜치의 `/docs` 폴더를 배포합니다. 별도 빌드 없이 `docs/index.html`을 브라우저로 열 수 있습니다. 준비물 체크는 체크한 브라우저에 저장됩니다.

기존 `guide.html` 링크도 여행 메인으로 이동합니다. 숙소처럼 특정 섹션을 가리키던 링크는 해당 위치까지 이어집니다.
